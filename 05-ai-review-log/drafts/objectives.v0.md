# Mục tiêu học tập (BẢN NHÁP v0 do AI tạo — chưa rà soát)

Sau khóa học, học viên có thể:

1. Hiểu Terraform state và remote backend.
2. Biết cách viết module Terraform tái sử dụng.
3. Viết test cho module bằng `terraform test`.
4. Hiểu OPA và ngôn ngữ Rego.
5. Viết policy Rego để kiểm tra plan.
6. Xây dựng pipeline CI/CD cho Terraform với GitHub Actions.
7. Nắm vững các best practice bảo mật khi dùng Terraform.
8. Troubleshoot các lỗi Terraform thường gặp.

Đánh giá: bài kiểm tra trắc nghiệm cuối khóa + capstone.
